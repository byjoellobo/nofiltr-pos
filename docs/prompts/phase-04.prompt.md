# Prompt — Phase 04: API and realtime

Paste the block below as the first message of a new chat.

```
Read CLAUDE.md, then docs/STATE.md.

We are on Phase 04 — API and realtime. The phase file is docs/phases/phase-04.md.
Read that file. Do not read any other phase file.

Do exactly ONE task: the next unchecked item in that phase. Do not start the
task after it, even if the one you finish is small.

Before you write code, tell me in three or four lines: which task you are doing,
which files you will touch, and any assumption you are making. Then wait for me
to say go.

When the task is done:
- run `make check` and make it pass
- update docs/STATE.md (tick the task, set the next one, note anything broken)
- append to docs/DECISIONS.md if you made a non-obvious choice
- commit as `phase-4/task-N: description`
- stop, and tell me what the next task is

If the task turns out to need more than one session, do not push through. Split
it into sub-tasks inside the phase file, commit that edit, and stop.
```
