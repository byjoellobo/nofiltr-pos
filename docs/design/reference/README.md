# Design reference archive

Phase 00 Task 2 copies everything from `claude-design/` into this folder and
writes an `INDEX.md` naming which surface and screen each file covers.

Once that is done, `claude-design/` in the base directory can be deleted. This
folder becomes the permanent record.

**Do not read this folder wholesale.** Open only the specific file for the
screen a task is building. It is large and reading it indiscriminately is the
fastest way to exhaust a session's context.
